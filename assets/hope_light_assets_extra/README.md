# Hope Light — дополнительный набор ассетов

Это дополнение к первому набору `hope_light_assets`. Первый набор не менялся, этот самостоятельный: в нём нет ссылок на файлы первого.

| Что | Где | Сколько |
|---|---|---|
| Модели (.glb) | `models/<локация>/` | 43 |
| Префабы Godot (.tscn) — модель + свет, готовые к расстановке | `prefabs/<локация>/` | 43 |
| Текстуры (PNG, 64 px ≈ 1 м) | `textures/` | 34 (13 из первого набора + 21 новая) |
| Карты нормалей | `textures/*_n.png` | для всех, кроме надписей и декалей |
| Материалы StandardMaterial3D (UV) | `materials/M_*.tres` | 34 |
| Материалы с world-triplanar (для CSG, GridMap, грейбокса) | `materials/triplanar/M_*_tri.tres` | 34 |

Всё проверено в Godot 4.5.1: модели, префабы и материалы загружаются без ошибок.

## Подключение

Скопируйте папку в проект по пути **`res://assets/hope_light_assets_extra/`**: по нему на файлы ссылаются префабы и материалы. Если папку потом нужно переместить, делайте это в файловой панели Godot, тогда ссылки обновятся сами.

- **Префаб** перетаскивается в сцену как есть. Если в модели есть маркер `LightPoint` / `RedLightPoint`, в префабе на его месте уже стоит OmniLight3D.
- **Материал** накидывается на любой меш, CSG-фигуру или GridMap-тайл. Triplanar-вариант не требует UV: текстура ложится в мировых координатах, 1 тайл = 1 м. Им удобно собирать комнаты прямо в редакторе.
- **Текстуры** пиксельные, у материалов уже выставлен фильтр Nearest.

Соглашения те же, что в первом наборе: метры, Y вверх, секции 4 м вдоль −Z, коллизии через суффиксы `-convcolonly` / `-colonly`, подвижные части — отдельные узлы с осью на петле (`Door`, `Lid`, `Gate`, `Lever`, `Wheel`, `Crank`, стрелки часов).

## Исходники

`source/hope_light_assets_extra.blend` — все модели набора в одном файле. `source/scripts/` — генераторы: `assets_extra.py` и `textures_extra.py` (используют `lib.py`, `assets.py` и `textures.py` из первого набора; копии лежат здесь же). Модели собираются командой `ASSET_MODULE=assets_extra ASSET_LIST=ASSETS_EXTRA python build.py <выход> <текстуры1>:<текстуры2>`.
