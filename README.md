# Тихая

Хоррор от первого лица на Godot 4.3+ (GDScript).

Ты обходчик глухой станции метро «Тихая». Каждый день ты спускаешься по узкому
наклонному спуску на станцию, где помещается одна вагонетка, и уходишь в длинный тоннель
выполнять поручения из журнала смен. Поручения простые: сжечь паутину, найти и поменять
фильтры, зарядить фонарь. Только с каждым днём становится всё яснее, что в тоннеле ты не один.

## Как запустить

1. Установи [Godot 4.3](https://godotengine.org/download) или новее (обычную версию, не .NET).
2. В менеджере проектов нажми **Import** и выбери `project.godot`.
3. Нажми **F5**.

Пока в проекте нет ни одного ассета: геометрия, текстуры (бетон, паутина) и все звуки
генерируются кодом.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | идти (раскладка не важна, используются физические клавиши) |
| Shift | бежать |
| Мышь | смотреть |
| E | действие; удерживать — зарядка фонаря, замена фильтра |
| ЛКМ | горелка: жечь паутину |
| F | включить/выключить фонарь |
| H | подсказка по управлению |
| Esc | освободить курсор |

## Геймплей

- **Фонарь** разряжается примерно за 5 минут. Заряжать его нужно на зарядных станциях
  (их зелёный огонёк видно в темноте). При низком заряде фонарь мигает.
- **Паутина.** Большая перекрывает тоннель целиком, маленькая висит по углам. Сжигается горелкой.
- **Пауки** безобидны: ползают по стенам, убегают от огня и плетут новую паутину.
- **Фильтры.** Забитый вентблок горит красным. Запасные фильтры лежат в ящиках по тоннелю,
  их нужно найти (с собой можно унести максимум 3).
- **Страх.** В темноте он растёт, от встреч с «ним» подскакивает. Если дойдёт до предела,
  герой теряет сознание и приходит в себя у входа.
- **Смена** заканчивается, когда все поручения выполнены и ты отметился в журнале наверху.

## Пять смен

С каждым днём ужаса больше: эхо шагов, которое не совпадает с твоими, надписи мелом,
силуэт на краю луча, сам по себе гаснущий свет, вагонетка, которая уехала,
паутина, выросшая там, где ты её только что сжёг, и, наконец, открытая решётка в конце тоннеля.

## Структура

```
project.godot          настройки, автозагрузка Game
scenes/main.tscn       единственная сцена (корень со скриптом main.gd)
scripts/
  game.gd              автозагрузка: день, поручения, страх, реплики, управление, звук
  main.gd              сборка мира, раскладка объектов по дням, паника, финал
  level.gd             геометрия: будка, спуск, станция, тоннель, лампы, решётка
  player.gd            игрок: движение, фонарь, горелка, взаимодействие
  director.gd          «режиссёр» хоррор-событий и сюжетных точек
  stalker.gd           «Другой»
  hud.gd               интерфейс
  geo.gd               построение примитивов
  proc_tex.gd          процедурные материалы и частицы
  sfx.gd               процедурные звуки
  props/               паутина, вентблок, ящик с фильтрами, зарядка, журнал, вагонетка, паук
```
